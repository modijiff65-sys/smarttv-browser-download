Why this one

Halka aur simple

8GB storage aur 2-core box ke liye banaya gaya. Dark theme, kam GPU load, chhota footprint.

Har format chalta hai

Video playback libVLC engine se — H.264, H.265/HEVC, VP9, AV1 sab. Chahe chip mein hardware decoder ho ya na ho.

Smart detection

Page pe koi bhi video ya media link mile, app khud use fullscreen native player mein khol deta hai.

Remote ke liye theek

D-pad navigation, Back button handling, fullscreen toggle — TV remote se aaram se chalta hai.

Install kaise karein

Do minute ka kaam

APK download karo

Upar wale button se, ya direct link se SmartTVBrowser-debug.apk download karo.

Box tak pahunchao

USB drive se copy karo, ya adb install SmartTVBrowser-debug.apk chalao.

Unknown sources on karo

Box pe Settings → Security → Unknown sources enable karo. (Debug build hai, isliye warning aayegi — normal hai.)

Install aur kholo

File manager se APK kholo, Install dabao. Launcher mein "SmartTV Browser" dikhega.

Note

Ye ek debug build hai (signed release nahi). Baad mein chaho to release build bana sakte hain — chhota aur signed.
